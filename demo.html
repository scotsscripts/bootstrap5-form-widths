Bootstrap 5 Form Width Utilities

Set form field widths on a 12-column scale, as block or inline fields.

576px and up: widths active Below 576px: fields are full width Resize the window to see the mobile fallback.

Load bs5-form-widths.css after Bootstrap's CSS, or Bootstrap's own field widths will override it: 
<link href="bootstrap.min.css" rel="stylesheet">
<link href="bs5-form-widths.min.css" rel="stylesheet">

The code under each example is the exact HTML of that example.

Block widths

Each field stacks on its own line. form-sm-1 through form-sm-12.

Inline widths without a wrapper

Fields sit side by side. Without a flex wrapper, browsers add a small whitespace gap between inline-block elements, so a row that adds up to 12 can wrap. Here, the 4 + 4 + 4 and 6 + 6 rows may not fit on one line:

Inline widths with a d-flex flex-wrap wrapper (recommended)

The flex wrapper removes the whitespace gap, so rows that add up to 12 fit exactly, and fields wrap cleanly when they don't.

Real-world example: address form

Put the width class on a wrapper div so the label and field move together. The field inside keeps Bootstrap's normal 100% width, so it fills the wrapper.

Real-world example: inline sign-in form

Labels, fields and the button sit on one line. Only the fields get a width class; the labels and button size themselves. This row doesn't add up to 12, so the whitespace gap doesn't matter and no flex wrapper is needed. Below 576px the fields go full width and stack under their labels.

The labels use d-inline-block so their top margin works on small screens (margins don't apply to plain inline elements). The button is type="button" only so the demo doesn't submit; use type="submit" in a real form.

This layout is meant for small inline forms. The labels and button take up space that the width classes don't count, so a row of fields that adds up to 12 (three form-sm-4-inline fields, for example) won't fit on one line and will wrap. Leave room for them, or put the labels above the fields like the address form.

Custom width

For a one-off size, override the --form-sm-w variable on any element that has a form-sm class.
